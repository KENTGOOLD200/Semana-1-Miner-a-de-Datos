Fundamentos de la Minería de Datos

Síntesis interactiva de los pilares cognitivos, analíticos y metodológicos.

Pase el cursor (o toque) sobre las tarjetas para revelar la información técnica.

1. Jerarquía Cognitiva

Progresión formal desde registros crudos hasta modelos accionables.

Conocimiento Accionable y Predictivo. Ej: Reglas de decisión, árboles.
Información Procesada y Contextualizada. Ej: Promedios, reportes.
Dato Crudo, pasivo. Vectores multidimensionales. Ej: "7.8"

2. Infoxicación

El problema del exceso de datos y la intervención de la minería.

El Problema: Acumulación masiva de información desestructurada que supera la capacidad de procesamiento humano, paralizando o sesgando la toma de decisiones organizacionales.

La Solución (Minería de Datos): Proceso analítico no trivial que extrae patrones válidos, novedosos y comprensibles, convirtiendo el ruido en ventaja competitiva.

3. Multidisciplinariedad

Convergencia estructural de tres áreas científicas fundamentales:

Estadística

Fundamento matemático para análisis inferencial y validación de hipótesis.

Machine Learning

Algoritmos capaces de generalizar comportamientos a partir de experiencia empírica.

Bases de Datos

Soporte tecnológico, supercomputación y escalabilidad para Big Data.

4. Taxonomía de Tareas

Clasificación analítica de los objetivos de extracción.

Predictivas (Aprendizaje Supervisado)

Entrada: Datos con variables independientes (X) y etiqueta (Y).
Objetivo: Estimar comportamientos o categorizar.
Ejemplo: Clasificación y Regresión.

Descriptivas (Aprendizaje No Supervisado)

Entrada: Datos sin etiquetas previas (Solo X).
Objetivo: Descubrir estructuras o agrupamientos ocultos.
Ejemplo: Clustering (Agrupamiento).

5. Proceso KDD

Fases del Descubrimiento de Conocimiento en Bases de Datos.

Nota: La aplicación del algoritmo (Fase 4) es solo una parte del ciclo.

  • 1. Selección

    Identificación de datos objetivo.

  • 2. Preprocesamiento

    Limpieza de ruido y datos faltantes.

  • 3. Transformación

    Reducción de dimensiones (Procesos ETL).

  • 4. Minería de Datos

    Aplicación del modelo matemático/algoritmo.

  • 5. Evaluación

    Interpretación de patrones y conocimiento.
